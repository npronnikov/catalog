Пример ролевого ревью

AI создаёт небольшой калькулятор. Владелец продукта проверяет результат, при желании привлекает DEV, QA и SA и возвращает замечания AI для доработки.

FLOW.yaml · metadata.yaml

Как запустить

  1. Выберите проект с Git-репозиторием и настройте AI-агента.
  2. Добавьте в команду пользователей с ролями PRODUCT_OWNER, DEV, QA и SA. Для совместного ревью понадобятся отдельные учётные записи.
  3. Создайте флоу из FLOW.yaml и опубликуйте его. При импорте каталога укажите своего агента и команду в metadata.yaml.
  4. Запустите новый Run с обязательным прохождением гейтов (require_all_gates). Можно добавить пожелание, например: «Добавь короткие комментарии к функциям».

Как устроен флоу

Создать калькулятор → Проверить результат → Готово
        ↑                    │
        └──── Доработка ──────┘

Результат — один файл role-review-fixture/calculator.js с функциями сложения и деления.

Попробуйте совместное ревью

  1. Под PRODUCT_OWNER откройте результат. Его можно утвердить сразу или отправить на ревью с предварительным решением Approve либо Rework.
  2. Под DEV, QA и SA проверьте файл, оставьте комментарии к коду и выберите Approve либо Rework. Например, DEV проверяет реализацию, QA — граничные случаи, SA — понятность контракта функций.
  3. Дождитесь всех трёх решений. Если каждое совпало с предварительным решением PRODUCT_OWNER, оно применяется автоматически. При расхождении окончательное решение принимает PRODUCT_OWNER.

Попробуйте доработку

Верните результат через Rework с замечанием, например: «Добавь проверку, что оба аргумента — числа».

Keep сохраняет текущие изменения для доработки. Discard откатывает их: AI создаёт файл заново с учётом замечаний. Для простого прогона выберите новую сессию (new_session).

AI получает замечания через rework_instruction и исправляет файл. После этого снова открывается проверка. Утвердите результат, чтобы завершить Run.
