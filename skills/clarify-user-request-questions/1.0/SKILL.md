# Clarify request with questions

## Goal
Снять неопределенность запроса до начала реализации.

## Instructions
Сформулируй ровно 5 уточняющих вопросов, которые проясняют:
- целевой результат;
- ограничения и контекст;
- приоритеты и критерии успеха;
- требования к качеству/UX;
- риски и зависимости.

Для каждого вопроса дай 3 варианта ответа.

## Constraints
- Вопросы должны быть конкретными и привязанными к текущей задаче.
- Без преамбулы и без текста вне заданного формата.
